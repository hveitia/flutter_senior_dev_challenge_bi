Avisos

Para qué existe este sitio, qué es y qué no es, y qué pasará con él cuando termine el proceso.

  • Propósito

    Este sitio, la consola desplegada y la aplicación existen únicamente como parte de un proceso de selección para una posición de desarrollador Flutter. Los preparé para que las personas que evalúan mi candidatura puedan probar el trabajo. No tienen ningún otro uso.

  • No es un sitio de una entidad financiera

    No es un producto, un servicio ni un sitio oficial de ninguna entidad financiera. No está afiliado a ninguna ni cuenta con su respaldo. «Banca Digital» es el nombre de una aplicación de demostración.

  • Datos ficticios

    Los clientes, las cuentas, los saldos, los movimientos y los aliados son ficticios. El dinero es de demostración y no tiene ningún valor. No se realiza ninguna operación bancaria real.

  • Credenciales

    En este sitio no se publican credenciales. Para entrar a la consola y a la aplicación, usa solo las credenciales de demostración que recibiste por correo de mi parte, y no las compartas fuera del equipo de evaluación.

  • No introduzcas datos personales reales

    La aplicación permite registrar un cliente nuevo y para ello pide un número de identificación, un nombre y un teléfono. Lo que se escribe se guarda en una base de datos de demostración. Si pruebas el registro, usa datos inventados.

  • Retirada

    Cuando el proceso de selección termine, eliminaré este sitio, el servidor desplegado, las cuentas de demostración y todos sus datos. Un servicio de prueba con apariencia de producto financiero no debe quedar publicado más tiempo del necesario.

  • Contacto

    Hector Veitia. Puedes escribirme respondiendo al correo con el que recibiste este enlace, o encontrarme en GitHub.
